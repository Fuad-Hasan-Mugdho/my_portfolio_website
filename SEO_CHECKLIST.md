# SEO launch checklist

The technical SEO foundation is included in the repository. Complete these external steps after deployment:

1. Add `https://fuad-hasan-mugdho.github.io/my_portfolio_website/` as a URL-prefix property in Google Search Console.
2. Verify ownership using the HTML-tag method. Add the provided verification meta tag inside `<head>`, deploy it, then click **Verify**.
3. Submit `https://fuad-hasan-mugdho.github.io/my_portfolio_website/sitemap.xml` in **Indexing → Sitemaps**.
4. Inspect the canonical portfolio URL with **URL inspection**, run the live test, and select **Request indexing**.
5. Test the deployed page with Google's Rich Results Test and confirm that the `ProfilePage` and `Person` graph has no critical errors.
6. Keep the same full name, professional title, portfolio URL, photo, GitHub URL, and LinkedIn URL across public profiles.
7. Link to the portfolio from GitHub, LinkedIn, relevant public project READMEs, and other genuine professional profiles.

Google decides ranking algorithmically. Technical SEO improves discovery and understanding but cannot guarantee a first-position result.
